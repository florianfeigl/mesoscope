% ------------------------------------------------------------------ Hallmarks
\begin{frame}[t]{Hallmarks}
  \begin{itemize}
    \item \textbf{Raspberry Pi 5 + AI HAT+} — Hailo-8 NPU (26 TOPS) for on-device
          cell classification
    \item \textbf{HQ Camera (Sony IMX477)} — C-mount, ZEISS 10$\times$/0.30,
          125~mm tube-lens optics module
    \item \textbf{OpenFlexure v3 stack} (FastAPI) deployed via custom Ansible roles
          with hard-won Pi~5 fixes (Hailo DKMS, pisp ISP patch)
    \item \textbf{Custom Z-focus-only body} — the X/Y flexure stage is removed; the
          linear rail provides the X scan instead
    \item \textbf{CVAT annotation server} (VPS, \texttt{cvat.feigl.dev}) feeding the
          NPU training pipeline
    \item \textbf{Tilted-microscope linear-rail concept} — IDANA becomes a
          \emph{moving imaging head} scanning a row of bioreactors
  \end{itemize}
\end{frame}

% ------------------------------------------------------------------ Upcoming challenges
\begin{frame}[t]{Upcoming challenges}
  \begin{itemize}
    \item \textbf{Tilting the device 90$^\circ$} — the stage is held by a bending
          plastic spring (flexure) built for gravity pulling straight down. On its
          side, gravity pulls sideways instead: will the stage sag and drift out of
          focus?
    \item \textbf{Camera sees less than we want to image} — one photo covers only
          $\approx$0.9~mm, but the \O5~mm culture window is much larger, so we must
          take many images and stitch them (needs a small vertical lift stage)
    \item \textbf{Custom back-lighting} — one near-infrared light source, fed by an
          optical fibre, riding along on the moving head (ModLight mirror variant)
    \item \textbf{Open mechanical details} — still to fix: spacing between
          bioreactors, which face the Z-motor rests on, and the adapter joining the
          carriage to the MGN12 linear rail
  \end{itemize}
\end{frame}
