# OpenFlexure Microscope STL Files

Download the STL files from the OpenFlexure v7 build server and place them in the appropriate subdirectories.

**Source:** https://build.openflexure.org/openflexure-microscope/v7.0.0-beta2/docs/high_res_microscope.html

## Directory Structure

```
stl/
  microscope-body/    Main body with flexure stage
  optics-module/      Camera + objective holder (HQ Camera variant)
  stage/              Sample stage and clips
  illumination/       LED illumination module and condenser
  motor-mounts/       Stepper motor mounting brackets
  tools/              Assembly jigs and alignment tools
```

## Print Settings (recommended)
- **Material:** PLA or PETG
- **Layer height:** 0.15-0.2mm
- **Infill:** 20-30%
- **Supports:** As indicated per part in OpenFlexure instructions
- **Nozzle:** 0.4mm
